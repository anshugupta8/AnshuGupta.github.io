# Anshu Gupta — Portfolio

A lightweight, responsive, single-page personal portfolio. Built with plain HTML, CSS and JavaScript; no build tools required.

## Publish on GitHub Pages
1. Create a public GitHub repository named `YOUR-USERNAME.github.io` (replace YOUR-USERNAME with your GitHub username).
2. Upload `index.html`, `styles.css`, `script.js`, and `resume.pdf` to the repository root and commit.
3. In repository **Settings → Pages**, select **Deploy from a branch**, branch **main**, folder **/(root)** and save.
4. Your site should become available at `https://YOUR-USERNAME.github.io/` after deployment.

Alternatively, use any repository name and access it at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Personalize before publishing
- In `index.html`, replace the placeholder `https://github.com/` link with your actual GitHub profile.
- Add your LinkedIn URL if desired (the uploaded résumé contains only the label "LinkedIn", not a URL).
- Review the employment date marked "Present" in the résumé and update if needed.
- Optionally add live project/demo links.

## Local preview
Open `index.html` in your browser.
