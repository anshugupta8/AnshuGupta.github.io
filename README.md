# Anshu Gupta — Portfolio

A responsive, static, single-page portfolio based on the résumé dated 28 October 2026.

## Publish on GitHub Pages

1. Create a public repository named `YOUR-USERNAME.github.io` (replace YOUR-USERNAME with your actual GitHub username).
2. Upload `index.html` and `resume.pdf` to the repository root.
3. Under Settings → Pages, choose Deploy from a branch, `main`, `/ (root)` and save.
4. Visit `https://YOUR-USERNAME.github.io/` after deployment.

## Edit

Edit `index.html` with any text editor. All layout and styling are contained in the file. Replace `resume.pdf` with an updated copy whenever needed. Add real LinkedIn/GitHub URLs only after verifying them.
